Privacy Policy

Last updated: November 23, 2026

Money Mechanics is a personal, single-owner project that produces short personal-finance videos and publishes them to its own YouTube channel through an automated pipeline running on the owner's own computer. This policy explains what data the project handles and how.

In short: Money Mechanics has no customers and no end users other than its owner. It does not collect, request, store, or share personal information from any visitor or third party. It uploads only the owner's own content to the owner's own channel.

Use of YouTube API Services

Money Mechanics uses YouTube API Services to upload the owner's own finished videos to the owner's own YouTube channel. By using this application, the owner agrees to the YouTube Terms of Service.

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Google's handling of any data it receives is governed by the Google Privacy Policy.

What the application accesses

  • YouTube (via OAuth 2.0): permission to upload videos to, and manage, the owner's own YouTube channel (scopes: youtube.upload and youtube). This access is used solely to publish the owner's own videos.
  • Google Sheets (via a service account): the application writes job status to a spreadsheet the owner owns, used as an internal production queue. No YouTube data or any other person's data is placed there.

The application does not access Gmail, Google Drive files other than the owner's own queue sheet, contacts, location, or any other Google service, and it does not read, collect, or process data belonging to any other YouTube user or channel.

Data storage and retention

  • Authorization tokens and the service-account key are stored only on the owner's local computer (in C:\shorts\keys\). They are never transmitted to any third party and are not shared.
  • Video scripts, audio, and finished video files are stored locally on the owner's computer.
  • No analytics, tracking, cookies, or visitor data are collected by this website or the application.

Data deletion and revoking access

Because the application stores no third-party personal data, there is no end-user data to delete. The owner can revoke the application's access to Google and YouTube at any time by:

  • Visiting myaccount.google.com/permissions and removing access for this application, and/or
  • Deleting the stored token file (yt_token.json) from the local computer.

Revoking access immediately stops the application from being able to upload or manage any content.

Third-party services

  • Anthropic (Claude API): used to draft and fact-check the text of each video script. Only script text is sent; no Google, YouTube, or personal data is shared with it.
  • Google (Sheets & YouTube APIs): as described above.

Children's privacy

Money Mechanics is general-audience financial-education content and is not directed to children under 13, and it does not knowingly collect any information from children.

Changes to this policy

If this policy changes, the updated version will be posted on this page with a new "last updated" date.
